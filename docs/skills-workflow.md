# Skills Workflow

Use skills from `skills.sh` to improve execution speed and consistency for repeatable tasks.

## Verify Installed Skills

```bash
npx skills ls
```

## Find Relevant Skills

```bash
npx skills find "your query"
```

## Install (Project-Level)

```bash
npx skills add vercel-labs/skills@find-skills -y
```

## Keep Skills Updated

```bash
npx skills check
npx skills update
```

Current project baseline includes:

- `find-skills`
- `frontend-design`
